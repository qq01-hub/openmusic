## 边界与后续观测

- 本次修改集中在客户端和说明文档，没有修改服务端接口、Socket 事件、Redis 模型、移动端桥接、配置或鉴权
- 收藏仍由服务端读取、写入与校正，共享索引仅加速当前服务端结果的查询，不是持久化来源
- 索引复用依赖客户端既有的不可变数组更新方式，后续修改歌曲身份或成员数据时应替换数组引用
- 大厅的原生内容可见性优化减少屏幕外布局和绘制，并不减少首次创建的 React 卡片数量；不支持该 CSS 的浏览器会回退到普通渲染
- 聊天继续使用原生动态行高，未重新启用已因重叠问题停用的绝对定位虚拟列表；持续加载大量历史后，DOM 数量仍会增长
- 沉浸视觉的 GPU、媒体解码与真实移动设备表现，需要在实际主题、机型、音源和网络下进一步测量
- 普通全屏歌词仍挂载完整歌词 DOM，本轮减少同一句内的重复 React 工作，没有实现长歌词虚拟滚动
- 歌单架保留最多 24 张卡片的既有展示范围与权限操作，浏览器验证覆盖进度绘制和提交次数，未验证真实账户下所有收藏、切歌、封禁操作
- 音域回响的可见性判断减少宿主准备和发送数据的工作，不代表 iframe 内所有 WebGL 动画、浏览器计时器或 GPU 资源已经释放
- Folia 的主题设置面板与共享资源加载仍有较大依赖，未将现有资源块警告视为已解决，也未对所有主题进行真实设备帧率测试
- 合成数据测试不覆盖生产 Redis、真实账户授权、外部音乐服务延迟或真实多人并发，不能将此次结果解释为这些链路的性能结论
