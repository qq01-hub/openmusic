# AI 外部搜索

在房间聊天中 @ AI 请求查询公开资料即可，模型需要支持工具调用，站点仍需在管理后台配置并启用 AI 模型

外部搜索由 OpenMusic 服务端执行，不依赖模型自带联网能力，无需另配搜索 API Key，也无需新增环境变量

## 内置来源与等待时间

内置 Bing RSS、百度公开搜索、DuckDuckGo Lite、搜狗网页、Bing 国内网页、DuckDuckGo HTML 和 Bing 国际网页，共 7 个入口，覆盖 4 个搜索服务

每批最多请求 2 个入口，取得有效结果后取消同批剩余请求，单批最多等待 4 秒，整次来源请求最多等待 16 秒，失败后切换下一批

来源可能因地区网络、反爬验证、限流或页面结构调整不可用，不绕过验证码，不把搜索失败解释成模型不支持联网，全部失败时明确告知未完成核实

只返回搜索结果的标题、真实来源链接和摘要，不请求结果网页正文，搜索结果作为不可信资料处理，不能覆盖系统规则或直接成为点歌候选

## 排查不可用

优先通过管理后台的模型连通性测试检查外部搜索，原生联网测试只验证供应商自身能力，两者不同

服务端 `ai-web-search` 日志包含来源、错误码、成功结果数量和耗时，不记录搜索词、凭据或网页内容

| 错误码 | 含义与处理 |
| --- | --- |
| `WEB_SEARCH_DNS_BLOCKED` | DNS 返回非公网地址或空结果，检查服务所在主机或容器的 DNS 与代理 Fake-IP 配置，使固定搜索域名解析到真实公网地址，不放行内网或测试网段 |
| `WEB_SEARCH_TIMEOUT` | 搜索来源连接或读取超时，检查出站网络 |
| `WEB_SEARCH_HTTP_403` / `WEB_SEARCH_HTTP_429` | 来源拒绝或限流，会继续尝试其他来源 |
| `WEB_SEARCH_NO_RESULTS` | 未解析到有效结果，可能无匹配结果、返回验证页或结构变化 |
| `WEB_SEARCH_STORAGE_UNAVAILABLE` | Redis 限流存储不可用，恢复 Redis 后再试 |
| `WEB_SEARCH_RATE_LIMITED` | 账户或全局搜索额度用尽，等待额度恢复 |
| `WEB_SEARCH_ACCOUNT_REQUIRED` | 缺少可信会话账户，需要恢复登录或会话 |

搜索仍沿用账户与全局 Redis 限流，固定 HTTPS 域名和路径、公网 DNS 校验、重定向校验、响应类型与大小限制，不能用关闭校验解决网络问题

## 发布与回滚

发布包含 `server/aiWebSearch.js` 和 `server/aiModelService.js` 的服务端版本并重启服务，网页指引随前端发布，无数据迁移、搜索 Key 或新增配置

验收时使用真实支持工具调用的模型，在后台测试并在房间请求一次公开资料查询，核对真实来源链接和 `room_ai_web_search_total`、`room_ai_web_search_provider_total` 计数及失败日志，这些计数和日志不代表完整监控告警

出现持续搜索失败、超时或结果解析异常时回退对应服务端版本并重启，无需更改 Redis 数据，基础房间功能继续可用
